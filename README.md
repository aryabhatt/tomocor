# tomocor

Interactive center-of-rotation finder for tomographic projections.

## Installation

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install tomocor:

```bash
pip install .
```

For development (editable install):

```bash
pip install -e .
```

## Usage

```bash
tomocor
```

or

```bash
tomocor </path/to/hdf5 file>
```
